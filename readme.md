Балансировку реализовал через механизм round robin. Но более качественного результата можно добиться через балансировку по занятому месту на стореджах.
Реализация может быть следующая: в фоне опрашиваем состояние стореджей и сортируем их по занятому месту, балансировщик выбирает первые n стореджей в которые нужно положить файл
